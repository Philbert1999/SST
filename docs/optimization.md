# 本轮优化记录

2026-10-19。目标：操作更顺手、数据失败后可恢复，保留现有策略及评分规则。

## 改动范围

- `app.py`：表单提交、价格范围校验、列表主动刷新、失败保留结果、日志空状态可见、图表绑定已完成筛选日期；快照写入失败时仍允许查看和导出结果。
- `data/akshare_provider.py`：不缓存空表，忽略旧空缓存，空主日线结果切换备用源；按数据源明确统一成交量和换手率，日线缓存版本升级；刷新列表时重置主日线源尝试。
- `data/cache.py`：先完成临时文件再原子替换；读取缺失或损坏文件返回缓存未命中；写入失败保留旧文件并记录日志。
- `strategy_framework/scanner.py`：将供应商已记录的日线获取失败同步到扫描错误列表，避免与“无策略信号”混淆。
- `performance.py`：快照文件名唯一、原子保存；单行日期错误被隔离，不中断其他股票复盘。
- 测试及 GitHub Actions：使用标准库 unittest 与 Streamlit 自带 AppTest，不添加测试框架依赖。

## 已知限制

- 本轮未做全市场长时间在线扫描或实际数据源可用率基准；恢复路径通过模拟断连验证。
- 未增加并发请求，避免在免费数据源上扩大限流压力。新浪接口及部分内部请求尚无统一硬超时保证。
- 新浪备用行情缺成交额时，流动性过滤仍可能排除这些股票；不生成估算成交额冒充真实数据。
- 复盘统计无有效样本时的零值展示、真实交易日历及复权口径的一致性仍需单独完善。
- 保留原项目的策略、参数、可选兼容模块，未重写界面或加入自动交易。
